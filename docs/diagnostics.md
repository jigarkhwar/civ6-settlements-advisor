# Как собрать диагностику для баг-репорта

Чтобы по баг-репорту было понятно, что происходило, нужны четыре вещи: **сохранение** того хода,
**лог мода**, **логи игры** и, при вылете, **отчёт о вылете**. На macOS всё это собирает один
скрипт; на Windows — вручную (раздел в конце).

## Один раз: включить вывод мода

Мод пишет свои сообщения через `print`. Версия игры для Mac не пишет `Lua.log`, поэтому вывод
забирает FireTuner-клиент проекта `tools/tuner.py`. Для него в игре должен быть включён Tuner:

- файл `~/Library/Application Support/Sid Meier's Civilization VI/Firaxis Games/Sid Meier's Civilization VI/AppOptions.txt`;
- строка `EnableTuner 1` (игра должна быть закрыта, пока правишь файл).

## Каждую игру: запустить запись лога

1. Запусти игру и загрузи партию — дождись карты.
2. В папке проекта, в отдельном терминале:

   ```bash
   python3 -I tools/tuner.py serve
   ```

   Не закрывай его, пока играешь. Он дописывает всё, что печатают мод и игра, в `logs/tuner.log`.
3. **После каждого перезапуска игры перезапусти и `serve`** (Ctrl+C и снова): старый держит
   соединение с закрытой игрой и молчит.

## Когда заметил ошибку

1. **Не закрывай игру.** Сделай быстрое сохранение: Esc → «Быстрое сохранение».
2. **Скриншот** (Cmd+Shift+4) — так, чтобы были видны метки, номера мест и подсказка, если дело в
   них.
3. **Координаты клетки**, о которой речь: наведи на неё курсор и выполни

   ```bash
   python3 -I tools/tuner.py exec -s SA_Main 'local p = Map.GetPlotByIndex(UI.GetCursorPlotID()); print(p:GetX() .. "," .. p:GetY())'
   ```

4. **Собери архив**, пока игра ещё запущена (так в него попадёт и состояние мода):

   ```bash
   tools/collect_diagnostics.sh
   ```

   Скрипт печатает путь к `logs/diagnostics-ДАТА.zip` и его размер.
5. **Создай issue** по форме «Ошибка» и перетащи туда zip и скриншот. Если архив больше 25 МБ
   (лимит GitHub), собери его с одним сохранением: `tools/collect_diagnostics.sh 1`.

## Что лежит в архиве

| Файл | Что это |
|---|---|
| `info.txt` | дата, версия macOS, коммит мода и незакоммиченные правки, куда указывает ссылка на мод, `EnableTuner`, запущена ли игра, включены ли мод и DMT (по `Modding.log`) |
| `tuner.log` | весь лог мода и игры из `tools/tuner.py serve` |
| `tuner-SA-lines.txt` | последние 300 строк мода с метками (таблица ниже) |
| `state.txt` | состояние мода в запущенной игре: ход, записи меток, очередь фоновой работы, последняя ошибка, выбранный юнит |
| `game-logs/` | логи игры: `Modding.log` (какие моды загрузились), `UserInterface.log`, `Database.log`, `UIWarnings.csv` и др.; `Lua.log` — если игра его пишет |
| `saves/` | два самых свежих сохранения (быстрое, автосохранения, ручные) |
| `crashes/` | отчёты macOS о вылетах игры за последние 2 дня (`Civ6_Exe_Child-*.ips`) |

## Если игра вылетела

Запусти `tools/collect_diagnostics.sh` сразу после вылета: в архив попадут лог до вылета, отчёт о
вылете и последнее автосохранение. В issue напиши время вылета и что делал в этот момент
(ходил Поселенцем, наводил курсор, нажал «Следующий ход»…).

## Метки в логе мода

| Метка | Значение |
|---|---|
| `SA_READY` | мод загрузился; `supported=false` — не Gathering Storm, мод ничего не показывает |
| `SA_DMT ready=` | подключился ли Detailed Map Tacks; `false` и `error=` — районы не раскладываются |
| `SA_ERROR` | ошибка в коде мода (с местом в файле) — главное, что нужно в баг-репорте |
| `SA_SLOW` | кадр фоновой работы или перерисовки дольше 30 мс: что это было и сколько мс |
| `SA_PINS` | мод переставил метки города: сколько убрал и поставил (частые большие числа = метки «прыгают») |
| `SA_PLAZA` | где спланирована Правительственная площадь |
| `SA_MISMATCH` | DMT и игра по-разному решили, можно ли поставить район |

## Windows (вручную)

Папка игры: `Документы\My Games\Sid Meier's Civilization VI\`. Упакуй в zip и приложи:

- `Logs\Lua.log` — лог мода (на Windows игра пишет его сама, Tuner не нужен), `Logs\Modding.log`,
  `Logs\UserInterface.log`;
- самое свежее сохранение из `Saves\Single\quick\` или `Saves\Single\auto\`.

## Приватность

В сохранениях — имя игрока в партии, в отчётах о вылете — имя пользователя macOS и модель
компьютера. Репозиторий приватный; не прикладывай архив к публичным обсуждениям.

# Contract: интерфейс 002

Дополняет [../../001-settler-site-lens/contracts/ui.md](../../001-settler-site-lens/contracts/ui.md).
Все тексты — ключи `LOC_SA_*` в обоих языках (FR-021).

## Вердикт над Поселенцем (US1, R2)

- Где: сообщение над Поселенцем (элемент `SA_MessageInstance` из 001), пока Поселенец выбран.
- Тексты:
  - `LOC_SA_VERDICT_HERE` — «Основывай здесь» + причина `LOC_SA_VERDICT_HERE_WHY` («№ 1 лучше только
    на {1} %, а дорога {2} ход.»);
  - `LOC_SA_VERDICT_HERE_BEST` — «Основывай здесь: это лучшее место рядом» (клетка «здесь» и есть № 1);
  - `LOC_SA_VERDICT_NEXT` — «Основывай в 1 ходе на отмеченной клетке» + та же причина; сообщение
    стоит над этой клеткой — это и есть отметка;
  - `LOC_SA_VERDICT_GO` — «Иди на № 1: +{1} к баллу, {2} ход. дороги»;
  - `LOC_SA_VERDICT_LOW_DATA` — добавка «мало данных — открой карту вокруг».
- Если `Verdict.Kind = nil` — сообщения нет (как в 001: «Нет законных мест рядом»).
- Сообщение «уточняется» из 001 главнее вердикта, пока тройка не готова.

## Строки подсказки (US2–US4, R9)

Порядок в блоке мода (после заголовка и строки «Дорога» из 001):

1. вердикт — только на клетке «здесь»;
2. `LOC_SA_WHY_GROWTH` — «Город вырастет примерно до {1} жит. → {2} район.» (+ «упирается в
   жильё» / «в еду»);
3. `LOC_SA_WHY_STRATEGY` — «Стратегия: {1} — {2}» (до двух причин сигналов);
4. `LOC_SA_WHY_SPECIALIZATION` — «Специализация: {1}»;
5. дальше — строки 001 (районы, вода, клетки, ресурсы, «Против № 1», числа).

Сумма числовых слагаемых по-прежнему равна заголовку (SC-004 из 001).

## Выпадающий список победы (US4, R7)

- Где: верхняя панель игры, стек `StaticInfoStack` (слева, после счётчиков торговых путей и послов,
  перед стратегическими ресурсами): при его изменении игра сама пересчитывает ширину полосы ресурсов
  (ловушка 25). Стек не найден — списка нет, выбор из сохранения действует.
- Кнопка: `LOC_SA_VICTORY_BUTTON` — «Цель: {1}», где {1} — выбранная победа или «Авто ({победа})» (`LOC_SA_VICTORY_AUTO_SHORT`).
- Пункты: `LOC_SA_VICTORY_AUTO` — «Авто: {1}», затем только включённые в партии победы (названия
  из `Victories.Name`, порядок — как в таблице ниже):

  | В спецификации | Тип в данных |
  |---|---|
  | Научная | `VICTORY_TECHNOLOGY` |
  | Культурная | `VICTORY_CULTURE` |
  | Религиозная | `VICTORY_RELIGIOUS` |
  | Военная | `VICTORY_CONQUEST` |
  | Дипломатическая | `VICTORY_DIPLOMATIC` (только Gathering Storm) |
- Выбор: записывается в `SA_Victory`, план и метки пересчитываются в фоне; липкость меток
  сохраняется.
- Подсказка кнопки: строка стратегии (как строка 3 выше) и пояснение `LOC_SA_VICTORY_HINT`.
- Горячая перезагрузка и выход: список возвращается в свой контекст до освобождения контекста.

## Сохранение

| Ключ | Значение | Чтение |
|---|---|---|

| `SA_Victory` | `AUTO` или `VICTORY_*` | при `LoadScreenClose`; пусто или неизвестно → `AUTO` |

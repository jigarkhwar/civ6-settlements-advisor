# Сверка с Staery/civ6-optimizer (2026-10-29)

Проект: https://github.com/Staery/civ6-optimizer — внешнее веб-приложение на Python (FastAPI) и
Lua-мод, который выгружает карту в `Lua.log`. Лицензия MIT. Код только прочитан, ничего не
скопировано (принцип X). Наш расчёт — в [algorithm.md](algorithm.md).

## Главное различие подходов

| | civ6-optimizer | Settlements Advisor |
|---|---|---|
| Где работает | отдельное веб-приложение, карта из `Lua.log` | внутри игры: линза, подсказка, метки |
| Правила | таблицы на Python, зашиты вручную | база игры (`GameInfo`) и DMT во время игры |
| Что видит | **всю карту**: выгрузка без проверки видимости, туман не моделируется | только открытое игроку, неоткрытое — ожидание по генератору карты |
| Заворот карты | не учитывается | соседство берётся у игры (`Map.GetAdjacentPlot`) |

## Пункт за пунктом

| Тема | civ6-optimizer | Мы | Вывод |

## Что взять как идеи (свой код, принцип X)

1. **Специализация городов**: лимит районов по реальному размеру города и выбор, какие районы
   строить в каком городе, вместо «все районы везде».
2. ~~**Ход Поселенца до места**~~ — сделано (R28).
3. **Региональные здания** (радиус 6 Фабрики, Зоопарка, Стадиона): Промзона и Развлекательный
   комплекс — там, где покроют больше городов.
4. **Веса доходов по типу победы** — настройка игрока.
5. **Детерминированные перезапуски поиска** раскладки.
6. **Правила наций для выбора места** — по данным игры, где можно (майя, инки, кхмеры, Россия).
7. **Лояльность** и **вулканы** в оценке места; **Жилой квартал** по привлекательности.

# Contract: интерфейс и встраивание в игру

Что мод показывает игроку и как подключается к игре. Решения обоснованы в
[research.md](../research.md) (R2–R7).

## Подключение (modinfo)

| Действие | Содержимое |
|---|---|
| `<Dependencies>` | Detailed Map Tacks (`4ecfcc62-5471-4435-b295-590df213e8d8`) |
| `FrontEndActions / UpdateText` | имя и описание мода (en_US, ru_RU) |
| `InGameActions / UpdateText` | `Text/SA_Text_en_US.xml`, `Text/SA_Text_ru_RU.xml` |
| `InGameActions / ImportFiles` | `Scripts/*.lua` |
| `InGameActions / AddUserInterfaces` | `UI/SA_Main.xml` (контекст `InGame`) |
| `InGameActions / ReplaceUIScript` | `LuaContext = PlotToolTip`, файл `UI/SA_PlotToolTip.lua` (после Expansion2) |

`AffectsSavedGames = 0`. В этой функции мод ничего не пишет в сохранение.

## Общие данные между контекстами

`ExposedMembers.SettlementsAdvisor`:

| Поле | Тип | Кто пишет | Кто читает |
|---|---|---|---|
| `Active` | bool | SA_Main: Поселенец выделен | подсказка |
| `GetLines(plotIndex)` | function → `{string}` | SA_Main | подсказка |

После обновления данных SA_Main вызывает `LuaEvents.PlotInfo_UpdatePlotTooltip()`.

## Поведение при выделении Поселенца

1. `Events.UnitSelectionChanged`. Если выделенный юнит игрока имеет `FoundCity`:
   - включается слой окраски (`Hex_Coloring_Government`), а слой воды игры выключается;
   - 4 ступени цвета по порогам `SettlerView.Thresholds` (FR-004);
   - «мало данных» — отдельный цвет; места, где город нельзя основать, не окрашиваются;
   - номера 1–3 рисуются якорями `WorldAnchor` над `Top` (FR-005): флажок метки из текстур игры (`MapPin`, `MapPinFlag`), цвет по месту — золото, серебро, бронза; под флажком балл места на плашке `YieldBacking`. Сообщения — тёмная плашка `Controls_DropShadow4`, как подпись метки. Свой XML на ресурсах игры, файлы DMT не копируются;
   - раскладка `Top[1]` рисуется полупрозрачными значками районов с бонусом (FR-016);
   - обрабатываемые клетки `Top[1]` отмечены маленькими значками еды или производства,
     прозрачнее значков районов (FR-016a).
2. Снятие выделения или выбор другого юнита — всё убирается, слои возвращаются как были (FR-002).
3. Наведение курсора (`MouseMove` → `UI.GetCursorPlotID()`, только при смене клетки):
   на законном месте раскладка и отметки клеток перерисовываются вокруг него, на остальных —
   вокруг `Top[1]`. Если раскладки места ещё нет, она ставится в очередь первой (FR-025, приоритет 1),
   а до готовности у места видна пометка «уточняется» (FR-016).

## Цвета

| Ступень | Цвет (ключ `UI.GetColorValue`) | Условие |
|---|---|---|
| 1 (лучшая четверть) | `COLOR_SA_TIER_1` (зелёный) | `Score ≥ q3` |
| 2 | `COLOR_SA_TIER_2` (жёлто-зелёный) | `q2 ≤ Score < q3` |
| 3 | `COLOR_SA_TIER_3` (жёлтый) | `q1 ≤ Score < q2` |
| 4 | `COLOR_SA_TIER_4` (оранжевый) | `Score < q1` |
| мало данных | `COLOR_SA_LOW_DATA` (серый) | `LowData` |

Цвета задаются в `Config/SA_Colors.xml`. Подбор оттенков и контраста — на этапе 1.

## Формат подсказки (при выделенном Поселенце)

```
Место для города: 24,5 (уточняется)             ← или без пометки
Против № 1: −2,5 (нет: пресная вода −3,3, нет: Вино −0,5, зато Лесопилка ×2 +1,3)
                                                ← для любого законного места, кроме № 1:
                                                  до 3 причин знака итога, затем «зато» одна обратная
Диапазон: 19,0–28,5 · неоткрыто 6 клеток        ← только если есть неоткрытые
  Клетки        +11,0  пойма ×3, холмы с шахтой ×2
                       еды хватает на 9 жителей из 13   ← если ограничила еда или жильё
                       низины: 1 м ×2; −1,5 за риск      ← если есть низины
  Вода и жильё   +3,0  река: 5 жилья
  Роскошь        +4,0  новый вид: вино
  Стратегические +1,0  железо
  Разовые доходы +0,5  лес ×4 (вырубка)
  Районы         +5,0  Кампус +3, Промзона +2 · оптимум доказан
    Акведук: нет пресной воды, +жильё
Место № 1 · тройка доказана                      ← на номерах; или «тройка уточняется»
Цены: еда 1, произв. 1, наука 1, культура 1, золото 0,5, вера 0,5
```

- Сумма строк слагаемых равна первому числу (FR-013).
- У каждого слагаемого не больше 3 причин, остальные сворачиваются в «и ещё N».
- Числа выводятся с одним знаком после запятой. Разделитель дробной части зависит от языка
  (`ru_RU` — запятая).
- Для запрещённой клетки выводится одна строка: «Город здесь основать нельзя: <причина>» (FR-014).
- Если Поселенец не выделен, подсказка игры не меняется (FR-015).

## Сообщения

| Ключ | Когда |
|---|---|
| `LOC_SA_MSG_NO_SITES` | на открытой карте нет законных мест |
| `LOC_SA_MSG_NO_SITES_NEARBY` | в радиусе 8 клеток нет законных мест |
| `LOC_SA_MSG_RULESET` | набор правил не Gathering Storm |
| `LOC_SA_MSG_NO_DMT` | DMT не удалось подключить, районы отключены |

Сообщения показываются строкой над номерами (якорь у Поселенца) и в подсказке.

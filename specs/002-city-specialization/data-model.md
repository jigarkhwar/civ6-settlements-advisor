# Data Model: Специализация городов и темп основания

Таблицы Lua в памяти контекста мода; в сохранение пишется только выбор победы. Сущности 001
(Site, Layout, Plan, PinRecord) — в [../001-settler-site-lens/data-model.md](../001-settler-site-lens/data-model.md).

## Strategy — стратегия империи (R4, R5)

| Поле | Тип | Правило |
|---|---|---|
| `Victory` | строка `VICTORY_*` или `"BALANCED"` | из выбора игрока или из сигналов |
| `Auto` | bool | выбор «авто» |
| `AutoVictory` | строка | победа по сигналам (показывается в пункте «Авто: …» списка) |
| `Roles` | `{ [DistrictType] = "key" \| "secondary" \| "filler" }` | ключевые: `SA_Rules.VICTORY_DISTRICTS[Victory]` + районы сигналов 1–3; заполнители — как `SA_Rules.IsFiller` |
| `Signals` | список `{ Kind, Target, Weight, Text, Params }` | отсортирован по весу ↓, затем по `Target`; `Kind` ∈ district, building, modifier, effect, ai |
| `Scores` | `{ [yield] = вес }` | сумма весов сигналов по доходам |

- Пересчитывается: при загрузке, при смене выбора, в начале хода (модификаторы политик и верований
  могут поменяться — как `RefreshModifiers` в 001).
- Валидация: каждая роль — для района, доступного цивилизации (`SA_Rules.SiteDistricts`); у
  `BALANCED` нет ключевых районов кроме сигналов 1–2.

## Forecast — прогноз города (R3)

| Поле | Тип | Правило |
|---|---|---|
| `Population` | целое | население через `FORECAST_TURNS` ходов, для своего города ≥ текущего |
| `Limit` | целое | `1 + ⌊(Population − 1) / DISTRICT_POPULATION_REQUIRED_PER⌋` |
| `LimitedBy` | `"food"` \| `"housing"` \| `"horizon"` | что остановило рост (для подсказки) |
| `Housing` | число | жильё места к концу горизонта |

## Specialization — специализация места или города (R5, R6)

| Поле | Тип | Правило |
|---|---|---|
| `Label` | строка дохода или района | по ключевым районам плана; иначе по району с наибольшим соседством |
| `Districts` | список `DistrictType` по приоритету | отобранные в лимит + районы вне лимита (`RequiresPopulation = 0`) |
| `Dropped` | список `{ District, Reason }` | не вошли в лимит или «даёт мало» |
| `Regional` | `{ [DistrictType] = число покрытых городов }` | для Промзоны и Развлекательного комплекса |

- Связь: `Layout` из 001 строится только по `Districts`; `PinRecord` хранит только их метки
  (FR-009).

## Verdict — вердикт Поселенца (R2)

| Поле | Тип | Правило |
|---|---|---|
| `Kind` | `"here"` \| `"next"` \| `"go"` \| `nil` | `nil`, если нет ни законной клетки рядом, ни достижимых мест |
| `Here` | индекс клетки | лучшая законная клетка с задержкой 0 (для `"here"`) или 1 (для `"next"`) |
| `Best` | индекс клетки | № 1 тройки (с темпом) |
| `Gain` | число | `Best` − `Here` в баллах с темпом |
| `Turns` | целое | задержка до `Best` |
| `LowData` | bool | у `Here` или `Best` больше половины круга не открыто |

- Порядок: «here», если клетка с задержкой 0 проходит порог `HERE_MARGIN`; иначе «next», если
  проходит клетка с задержкой 1; иначе «go».
- Переходы между видами — только при выходе разницы за `HERE_MARGIN` с запасом `KEEP_MARGIN`
  (липкость 001).

## VictoryChoice — выбор победы игрока (R7)

| Поле | Хранение | Правило |
|---|---|---|
| значение | `PlayerConfigurations[pid]:GetValue("SA_Victory")` | `"AUTO"` (по умолчанию, если пусто) или `VICTORY_*`, включённая в партии; неизвестное значение → `"AUTO"` |

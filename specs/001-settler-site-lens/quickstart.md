# Quickstart: проверка линзы мест

Как убедиться, что функция работает: автономно и в игре. Детали — в
[contracts/ui.md](contracts/ui.md) и [data-model.md](data-model.md).

## Подготовка (один раз)

1. Lua 5.1.5 для тестов (R1):

   ```bash
   bash tools/setup_lua.sh
   ```

2. Выгрузка правил игры для поддельного мира: скрипт читает
   `~/Library/Application Support/Sid Meier's Civilization VI/Firaxis Games/Sid Meier's Civilization VI/Cache/DebugGameplay.sqlite`
   в режиме только чтения и пишет `tests/fixtures/gameinfo.lua`.
   Кэш должен быть от партии Gathering Storm.

   ```bash
   python3 -I tools/export_gameinfo.py
   ```

3. Мод в папку модов игры, ссылкой на рабочую копию:

   ```bash
   ln -s "$PWD/SettlementsAdvisor" "$HOME/Library/Application Support/Sid Meier's Civilization VI/Sid Meier's Civilization VI/Mods/SettlementsAdvisor"
   ```

4. В игре: «Дополнительный контент» → «Моды» → включить Detailed Map Tacks и Settlements Advisor.

5. Отладочный вывод (по желанию, с согласия пользователя: меняет настройки игры): `EnableTuner 1`
   в `AppOptions.txt`, затем в отдельном терминале:

   ```bash
   python3 -I tools/tuner.py serve
   ```

## Автономные тесты

```bash
.tools/lua51/bin/lua tests/run.lua
```

Ожидаемый результат: все тесты зелёные. В частности:
- слагаемые места в сумме равны баллу (SC-004);
- решатель совпадает с полным перебором на малых случаях (SC-007);
- повторный расчёт даёт тот же результат (SC-008);
- исправления DMT: без обёртки ошибка воспроизводится, с обёрткой — нет;
- ключи текстов совпадают в en_US и ru_RU (SC-010).

## Проверка в игре

Результаты проверок записываются в раздел «Результаты проверки в игре» файла [plan.md](plan.md) (конституция, принцип VI).

Нужны сохранения Gathering Storm в `tests/saves/` (их делает игрок, в репозиторий не кладутся):
`early.Civ6Save` (ход 5–10, есть Поселенец), `mid.Civ6Save` (ход 100+, Поселенец, 6+ городов),
`coast.Civ6Save` (Поселенец у побережья и реки с поймами).

## Снимки реальных карт для тестов

```bash
python3 -I tools/tuner.py snapshot mid
```

```bash
python3 -I tools/snapshot_to_fixture.py mid
```

После этого `tests/run.lua` гоняет инварианты и на этой карте. Снимок содержит только открытое игроку.

## Проверки этапа 0 (до основной реализации)

Пункты research с пометкой «проверить в игре»:
- `UnitManager.CanStartOperation(..., FOUND_CITY, ...)` для произвольной клетки (R8);
- выключенный слой воды не включается обратно миникартой (R3);
- `ReplaceUIScript` подсказки применяется после Expansion2, `ExposedMembers` виден из неё (R5);
- смысл констант Акведука и правило Дамбы (R11);
- параметры `FeatureRemovedFromMap` (R7), масштаб разовых доходов по скорости игры (R14);
- текущий шаг подъёма моря из UI и номер шага из `RandomEvents` (R23);
- вызов `CityManager.GetOperationTargets` для района (R27).

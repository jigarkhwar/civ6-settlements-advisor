# Как собрать диагностику для баг-репорта

Чтобы по баг-репорту было понятно, что происходило, нужны: **сохранение** того хода, **лог
мода** (`Lua.log`), **логи игры**, при вылете — **отчёт о вылете**, и **версии** (Windows,
видеокарта, какие файлы мода стоят в игре). Всё это собирает один скрипт в один zip.

## Windows

### Один раз

1. Скачай из репозитория два файла в одну папку (например, на рабочий стол):
   [`tools/collect_diagnostics.cmd`](../tools/collect_diagnostics.cmd) и
   [`tools/collect_diagnostics.ps1`](../tools/collect_diagnostics.ps1).
2. Включи вывод модов в `Lua.log`: закрой игру, открой
   `Документы\My Games\Sid Meier's Civilization VI\AppOptions.txt` и поставь `EnableTuner 1`
   (по умолчанию там 0). Сохрани файл.

### Когда заметил ошибку

1. **Не перезапускай игру**: `Lua.log` перезаписывается при каждом запуске. Сделай быстрое
   сохранение (Esc → «Быстрое сохранение»).
2. **Скриншот** (Win+Shift+S) — так, чтобы были видны метки, номера мест и подсказка, если дело
   в них. Если речь о конкретной клетке, опиши, где она (рядом с каким городом, ресурсом).
3. **Двойной щелчок по `collect_diagnostics.cmd`.** Игру закрывать не нужно. В конце окно
   покажет путь к архиву `SA-diagnostics-ДАТА.zip` на рабочем столе.
4. **Создай issue** по форме «Ошибка» и перетащи туда архив и скриншот. Если архив больше 25 МБ
   (лимит GitHub), запусти скрипт с одним сохранением — в PowerShell из папки со скриптом:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\collect_diagnostics.ps1 -Saves 1
   ```

### Если игра вылетела

Запусти `collect_diagnostics.cmd` **до** нового запуска игры: в архив попадут `Lua.log` до
вылета, отчёты Windows о вылете (WER, дампы из `%LOCALAPPDATA%\CrashDumps`, записи журнала
«Приложение») и последнее автосохранение. В issue напиши время вылета и что делал в этот момент
(ходил Поселенцем, наводил курсор, нажал «Следующий ход»…).

### Что лежит в архиве

| Файл | Что это |
|---|---|
| `info.txt` | дата, версия Windows, память, видеокарта и драйвер, запущена ли игра, `EnableTuner` и разрешение из `AppOptions.txt`, включены ли мод и DMT (по `Modding.log`), где лежат их папки |
| `lua-SA-lines.txt` | последние 300 строк мода с метками (таблица ниже) |
| `game-logs/` | все логи игры до 50 МБ: `Lua.log` (вывод мода), `Modding.log` (какие моды загрузились), `UserInterface.log`, `Database.log` и др. |
| `saves/` | два самых свежих сохранения (быстрое, автосохранения, ручные) |
| `crashes/` | отчёты Windows о вылетах игры за 2 дня и события журнала «Приложение» с Civilization |
| `mods/` | `.modinfo` мода и DMT; `SettlementsAdvisor-files.txt` — каждый файл мода с SHA-256 и датой: по ним видно, какая версия кода стоит в игре |

## macOS

Версия игры для Mac не пишет `Lua.log`: вывод мода забирает FireTuner-клиент проекта.

1. Один раз: `EnableTuner 1` в
   `~/Library/Application Support/Sid Meier's Civilization VI/Firaxis Games/Sid Meier's Civilization VI/AppOptions.txt`.
2. После загрузки партии, в папке проекта — и не закрывать, пока играешь (после каждого
   перезапуска игры перезапустить: старый держит соединение с закрытой игрой и молчит):

   ```bash
   python3 -I tools/tuner.py serve
   ```

3. Заметил ошибку — быстрое сохранение, скриншот (Cmd+Shift+4), затем, не закрывая игру:

   ```bash
   tools/collect_diagnostics.sh
   ```

   Архив — `logs/diagnostics-ДАТА.zip`: лог мода (`tuner.log`, `tuner-SA-lines.txt`), логи игры,
   сохранения, отчёты о вылетах (`Civ6_Exe_Child-*.ips`), версии и состояние мода в запущенной
   игре (`state.txt`: ход, записи меток, очередь фоновой работы, последняя ошибка).
4. Координаты клетки под курсором:

   ```bash
   python3 -I tools/tuner.py exec -s SA_Main 'local p = Map.GetPlotByIndex(UI.GetCursorPlotID()); print(p:GetX() .. "," .. p:GetY())'
   ```

## Метки в логе мода

| Метка | Значение |
|---|---|
| `SA_READY` | мод загрузился; `supported=false` — не Gathering Storm, мод ничего не показывает |
| `SA_DMT ready=` | подключился ли Detailed Map Tacks; `false` и `error=` — районы не раскладываются |
| `SA_ERROR` | ошибка в коде мода (с местом в файле) — главное, что нужно в баг-репорте |
| `SA_SLOW` | кадр фоновой работы или перерисовки дольше 30 мс: что это было и сколько мс |
| `SA_PINS` | мод переставил метки города: сколько убрал и поставил (частые большие числа = метки «прыгают») |
| `SA_PLAZA` | где спланирована Правительственная площадь |
| `SA_MISMATCH` | DMT и игра по-разному решили, можно ли поставить район |

## Приватность

В сохранениях — имя игрока в партии; в отчётах о вылетах и `info.txt` — имя пользователя
Windows или macOS в путях и модель видеокарты. Репозиторий приватный; не прикладывай архив к
публичным обсуждениям.

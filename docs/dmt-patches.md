# Исправления Detailed Map Tacks

Конституция, принцип II: файлы DMT не копируются и не меняются; ошибки исправляются обёртками
только внутри Lua-состояния мода. Каждое исправление описано здесь и покрыто тестом.

DMT: Workshop 2428969051, версия 2024-01-17
([исходники](https://github.com/hanweizhang/Civ6DetailedMapTacks)).
